# 🚀 Stack Social

> A modern social media platform built with **Next.js 16, React 19, Supabase, LiveKit, and Tailwind CSS**, combining content sharing, real-time messaging, stories, and HD voice/video calling into a single seamless experience.

---

## 🌟 Overview

Stack Social is designed to provide users with everything they need to create, connect, and communicate on one platform.

Users can:

* 📸 Share photos and videos
* 📖 Create and view stories
* ❤️ Like, comment, and bookmark posts
* 👥 Follow other users
* 💬 Chat in real-time
* 🎙 Send voice notes
* 📞 Make voice and video calls
* 🔒 Manage privacy settings
* 🎯 Discover personalized content

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/your-username/stack-social.git
cd stack-social
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

LIVEKIT_API_KEY=
LIVEKIT_API_SECRET=
LIVEKIT_URL=
```

### 4. Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
